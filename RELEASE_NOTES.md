# Cadence 0.7.3 Beta

Open existing projects in place, including projects saved outside the Cadence library. The project chooser remembers their locations. Save Cut As keeps a second named edit within the same project.

Cadence reopens the last active cut and can recover unfinished edits while preserving the named save. If older copies disagree, you can choose which edit to open. If an autosave is damaged, Cadence preserves its bytes and offers any readable saved or device copy. A missing project data folder produces an error, and a successful named save reports a separate warning if its recovery copy could not be written.

This release also includes text and adjustment layers and updates to credits from the 0.7.2 development build.
